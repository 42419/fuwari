RSS（Really Simple Syndication）是一种开放的内容订阅方式。相比社交平台的“推荐流”，RSS 更像把你喜欢的网站装进自己的收件箱——想看谁、看多少、什么时候看，全由你说了算。

:::tip[一句话总结]
RSS = 你自己掌控的信息流，不被算法牵着走。
:::

## 1. RSS 能解决什么问题

- **信息更可控**：你决定看什么，阅读器不会偷偷替你“优化”。
- **更新更及时**：博客、播客、资讯站一更新就能收到提醒。
- **阅读更安静**：无广告、无干扰，专注内容本身。

## 2. 如何找到 RSS 地址

多数网站都会提供订阅地址，找它就像找“订阅按钮”，常见位置与形式如下：

- **页脚/导航栏**：会写 “RSS/订阅/Feed”。
- **约定路径**：`/rss.xml`、`/feed.xml`、`/atom.xml`、`/feed`。
- **浏览器开发者工具**：查看网页源码里是否包含 `application/rss+xml` 或 `application/atom+xml`。

以本博客为例，默认订阅地址为：

```bash
https://www.yunov.top/rss.xml
```

:::note[小提示]
如果你部署在子路径或使用自定义域名，请把上面的地址替换成你的实际域名即可。
:::

## 3. 选择一个 RSS 阅读器

你可以根据平台选一个顺手的阅读器：

- **桌面端**：NetNewsWire（macOS/iOS）、Reeder（macOS/iOS）、Fluent Reader（Windows/macOS/Linux）。
- **Web 端**：Feedly、Inoreader、Tiny Tiny RSS（自托管）。
- **阅读稍后**：Readwise Reader、Pocket（部分支持 RSS）。

选择标准也很简单：

- 是否多设备同步
- 是否支持标签/文件夹
- 是否支持全文抓取

## 4. 订阅步骤（通用）

1. 在阅读器里找到 **Add / 订阅** 按钮
2. 粘贴 RSS 地址
3. 选个文件夹或标签“安放”它
4. 完成订阅，坐等更新就好

:::important[别忘了这一步]
第一次订阅后，给你的 RSS 源起个清晰的名字（比如「技术资讯」「写作灵感」），后期整理会轻松很多。
:::

## 5. 用好 RSS 的几个技巧

- **按主题分组**：比如「技术」「写作」「设计」「行业」。
- **设置阅读窗口**：每天固定 10-20 分钟清理未读。
- **善用过滤规则**：过滤低价值内容，只保留核心信息。
- **导入/导出 OPML**：换阅读器时一键迁移。

:::tip[OPML 是什么？]
它是 RSS 订阅源的「打包清单」。换阅读器时导出一次就能无缝搬家。
:::

## 6. 常见问题

**Q：订阅地址打不开？**

可能站点未开启 RSS，或地址不正确。试试在官网搜索 “RSS”，不行就联系站长确认。

**Q：内容只显示摘要？**

部分站点会限制全文。可以试试阅读器的“全文抓取”功能。

**Q：订阅数量多了看不过来？**

减少低频站点、只保留高价值源，再设个“稍后阅读”分区更省心。

:::warning[温馨提醒]
别一口气订太多源，信息焦虑会反弹。先从 5-10 个高质量站点开始，慢慢加。
:::
